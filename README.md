# 🚑 Cuestionario de Repaso de Emergencias Sanitarias

## Descripción

Actividad interactiva desarrollada en HTML, CSS y JavaScript para repasar conocimientos fundamentales del primer curso del Ciclo Formativo de Grado Medio en Emergencias Sanitarias.

El cuestionario presenta preguntas tipo test sobre:

- Identificación y uso de material sanitario.
- Atención extrahospitalaria en emergencias.
- Primeros auxilios.

Las preguntas se muestran de una en una y ofrecen retroalimentación inmediata para favorecer el aprendizaje y la autoevaluación.

---

## Destinatarios

Esta actividad está dirigida principalmente a:

- Alumnado de primer curso de Emergencias Sanitarias.
- Alumnado que inicia segundo curso y necesita realizar un repaso de contenidos.
- Docentes que deseen utilizar un recurso interactivo de autoevaluación en el aula o como tarea autónoma.

---

## Objetivos didácticos

Al finalizar la actividad, el alumnado debería ser capaz de:

- Reconocer material sanitario básico y su utilización.
- Identificar procedimientos fundamentales de atención extrahospitalaria.
- Aplicar conceptos básicos de primeros auxilios.
- Valorar su nivel de preparación antes de comenzar segundo curso.

---

## Características de la actividad

✅ 20 preguntas tipo test.

✅ 4 opciones de respuesta por pregunta.

✅ Preguntas mostradas de forma individual.

✅ Feedback inmediato tras cada respuesta.

✅ Visualización automática de la respuesta correcta.

✅ Cálculo de puntuación final.

✅ Mensaje de valoración según el resultado obtenido.

✅ Posibilidad de repetir la actividad.

✅ Diseño responsive compatible con ordenador, tablet y móvil.

## Instrucciones de uso

### Para el alumnado

1. Abrir el archivo `index.html` en un navegador web.
2. Leer las instrucciones iniciales.
3. Pulsar el botón **"Comenzar actividad"**.
4. Seleccionar una respuesta para cada pregunta.
5. Revisar el feedback recibido.
6. Pulsar **"Siguiente pregunta"** para continuar.
7. Consultar la puntuación final al terminar.
8. Utilizar el botón **"Repetir actividad"** si se desea realizar de nuevo.

---

### Para el profesorado

1. Descargar todos los archivos en una misma carpeta.
2. No modificar los nombres de los archivos.
3. Abrir `index.html` en un navegador actualizado.
4. Utilizar la actividad como:
   - Repaso inicial de curso.
   - Actividad de consolidación.
   - Autoevaluación.
   - Actividad complementaria.

## Criterios de evaluación de funcionamiento

La actividad se considera funcional cuando:

- Las preguntas se muestran una a una.
- Cada pregunta presenta cuatro opciones.
- Se proporciona feedback inmediato.
- La puntuación final es correcta.
- El cuestionario puede reiniciarse.
- La actividad se visualiza correctamente en el navegador.
